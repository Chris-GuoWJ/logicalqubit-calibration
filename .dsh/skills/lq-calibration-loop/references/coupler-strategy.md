# 耦合器策略

## 目标与依赖

保持比特顺序、拓扑连接、π 标定、Z→IF 映射、reference_z 和共振选择一致。
分别理解 tuning_z_range（调谐比特 Z 的映射支路）、
bounds/coupler_z_values（耦合器 Z）与 times_ns（交换时间）。
每个耦合器 BO 点对应一整条时间曲线，不是一个 QPU job。

当前 BO score = ptp(P01) × max(0, -corr(P01,P10))，loss=-score。
因此直接优化的是交换可见度及反相关，不是拟合 g 最大值，也不是 iSWAP 门保真度。
noise_variance 来自条件于当前参考矩阵的 shot-noise bootstrap，
未完全包含参考标定误差、漂移和其他系统误差。

manifest 的 readout_correction=false 指 SDK 采集 raw IQ 时关闭云端修正。
当前本地分析仍用四参考构建 assignment matrix 并修正联合概率：
CSV 中 p00/p01/p10/p11 是本地修正后值，*_raw 是本地分类后的未修正值，
并非原始模拟 IQ。读取同 run 的 readout_calibration.json 核对矩阵和 reference_job_ids；
不要因 manifest 这个标记就把 p 与 p_raw 的差异误判为数据矛盾。

## 分析顺序

1. 检查四个联合参考任务与读出修正来源，核对概率是否有严重非物理解或不稳定修正。
   不静默裁剪概率来伪造更好曲线。
2. 按 coupler_z 分组读取 joint_probabilities：P01 与 P10 是否存在反相交换，
   检查振幅、P00/P11 变化和重复性。当前两比特数据不能单独确认 |2> 等泄漏。
3. 检查时间步长/窗口是否能分辨振荡、是否有混叠、是否只看到局部单调片段。
4. 拟合 g 时检查模型、残差、置信区间、衰减和拟合可靠性；
   若没有拟合结果，不从 score 推算 g。不要混淆 g 与 2g 或 Hz/GHz/MHz。
5. 比较 score 的改善是否超出测量误差，并用独立完整曲线复测。

## 参数调整

- 低 contrast 且无明显交换：优先检查共振映射和已有 π/读出依赖，
  不同时修改耦合器 Z、tuning Z、XY 振幅和多个时序参数。
- score 随 Z 单调增加并贴边：说明当前范围内未见最优内部点。
  只有在任务硬边界内才可扩展，并保留重叠；达到硬边界时报告“范围受限候选”。
- 时间曲线采样过稀：在预算内减小时间步长；窗口不足则延长窗口。
  每次计算 4 + Z点数×时间点数 的 jobs，BO 时 Z点数=steps。
- score 平台或最佳几条差异小：对候选及邻点做独立网格完整曲线复测。
  coupler 网格要求至少 2 个 Z 点、至少 8 个整数 ns 时间点。
- 需要更快门或更大 g 时明确这是新目标；当前 score 不能自动代表该目标最优。
  最大交换对比度位置可以与最大 g/最佳门性能位置不同。

## 结果解释示例

如果最佳观测点接近搜索边界，应执行边界诊断和独立复测，并将结果报告为
“范围受限候选”。优化 score 不是门保真度，也不自动授权扩大耦合器幅度范围。
