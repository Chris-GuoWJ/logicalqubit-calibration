# Z 频率策略

## 目标与分组

对每个固定 Z 偏置分别优化 drive IF，目标为最大化 S（loss=-S）。
每个 Z 有自己的 XY-off 参考。不要跨 Z 混合拟合为一个一维 IF 曲线。
读取 π 标定来源/时间、manifest、按 Z 分组的 observations 及 frequency_candidates。

## 决策

- 先由已有有效 Z→IF 数据和硬件快照估计各 Z 的搜索窗口，保持 GHz IF 单位。
- 当前 zfreq_bo 的 bounds 是所有 Z 共用的 IF 窗口。
  各 Z 的峰相差较大时取覆盖所有目标的窗口；若需分组窗口，分别新建计划，
  每个计划仍至少 2 个 Z 点，不能假定支持每个 Z 单独的 bounds。
- 候选在窗口边界或只有单调趋势：窗口没有夹住峰，不能作为可靠共振点。
  在授权硬边界内扩窗并保留重叠；不能自动扩大 Z 扫描范围。
- 只有孤立高点：围绕候选做固定网格谱线验证，覆盖峰两侧，核对线宽和重复性。
- 相邻 Z 出现频率跳变：检查竞争谱峰、低信号、标定漂移及窗口截断。
  不按预期曲线强制平滑，不把曲线不连续一律判作噪声。
- 在峰远低于背景变化或重复不成立时停止自动标定，报告需要检查的实验条件。

## 验证与发布

用 `kind=zfreq` 的固定网格验证候选谱峰；每个比特 IF 轴至少 3 点，
每个计划 Z 轴至少 2 点。先确认现有 schema 能表达计划，再计算预算。
固定网格分析中的 significance 基于背景统计，是项目诊断量，不是通用的严格 p 值。
BO 的 at_search_boundary 与固定网格 at_scan_boundary 语义不同，需结合实际坐标判断。
当前 publish_z 路径针对固定网格分析，拒绝 BO run；不要直接拿 BO 候选文件发布。
正式配置保持只读，将可复现候选及独立验证证据交给发布流程。

## 已有窗口风险示例

旧样例 Z 包括 +0.2，而旧 Q9 映射中对应 IF 约 +0.22 GHz；
样例 bounds=[-0.13, +0.17] 可能截断该峰。
重新读取当前映射和采集时间后，才能决定本轮窗口；旧映射不代表当前真机准确频率。
