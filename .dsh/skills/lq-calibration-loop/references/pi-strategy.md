# π 振幅策略

## 目标与数据

读取本轮 manifest、observations.csv、已使用 π/读出设置。
优化量 S 为驱动态与 XY-off 参考态的 IQ 均值距离，loss=-S。
它是激发/读出差异的候选信号，不是直接测得的 P1 或 π 门保真度。
第一 Rabi 峰的确认需要覆盖峰两侧的实测扫描及适当独立验证；
较高阶激发峰也可能很高，不能仅凭最大 S 识别第一峰。

## 决策

- 未知峰位置：在已授权物理范围内做覆盖足够的粗扫描，确认基线与峰两侧。
- 峰在内部且两侧有下降：缩小下一轮区间，保留两侧支撑点；用更密网格或 BO 精化。
- 最优点距边界不足全宽 5%：把它作为边界警示，不宣布已找到全局最优。
  仅在任务硬边界内适度扩展该侧，并保留重叠区域以检查漂移；到硬边界即停止扩展。
- 平顶/近邻点差异与误差相当：优先独立复测候选及邻点，报告可接受区间，
  不把数值小数位更多当成更高精度。
- 低信号：检查驱动 IF、参考/读出配置与波形是否一致。
  `S <= 3*sqrt(noise_variance)` 可作启发式警示，不把它当作完整显著性检验。
- 信号随时间漂移：用同参数独立参考与复测诊断；不要把时间漂移拟合成振幅效应。

## 复测与停止

固定 duration_ns、envelope、drive IF、读出条件，只改变本轮获准的振幅等参数。
需要重复同一振幅时，用独立 pi_grid 小计划；单个振幅轴仍需至少 3 个严格递增点，
例如候选与两邻点，跨新 run 获得重复测量。不要靠重复 seed 或强行重复 BO 点完成复测。
在用户约定的容差与验证预算内，候选重复成立才报告验证结论；
若候选差别不能分辨，报告精度/区间受噪声限制。
需要 RB/IRB 的门性能结论应交由专门验证流程，当前 CLI 没有 RB/IRB kind。

## 结果解释示例

若候选附近有多个相近观测点，应先判断平顶和噪声，再选择精化或独立复测，
不可据此直接更新正式 π 标定。条件 LOO RMSE 与优化信号 S 同量纲，不能解释为门误差率。
